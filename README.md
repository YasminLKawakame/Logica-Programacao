# Lógica de Programação - SENAI

## About

Este repositório reúne atividades, exercícios, desafios e jogos desenvolvidos durante as aulas de **Lógica de Programação do SENAI**, utilizando JavaScript e Node.js.

O objetivo é praticar os fundamentos da programação por meio de exercícios práticos, desenvolvendo o raciocínio lógico e a capacidade de resolver problemas utilizando algoritmos.

## Tecnologias utilizadas

- JavaScript
- Node.js
- readline-sync
- Visual Studio Code

## Conteúdos trabalhados

- Variáveis e tipos de dados.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (if, else e switch).
- Estruturas de repetição (for, while e do...while).
- Arrays e manipulação de dados.
- Funções.
- Objetos.
- Entrada e saída de dados pelo terminal.
- Lógica e resolução de problemas.

## Organização do projeto

O repositório está organizado em três pastas principais:

- **Atividades:** exercícios desenvolvidos durante as aulas.
- **Desafios:** atividades práticas para exercitar o raciocínio lógico.
- **Jogos:** pequenos projetos desenvolvidos utilizando os conceitos de programação.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/YasminLKawakame/Logica-Programacao.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Logica-Programacao
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Execute o arquivo JavaScript desejado:

   ```bash
   node caminho-do-arquivo.js
   ```

## Objetivo

Desenvolver e fortalecer o raciocínio lógico e os fundamentos da programação, aplicando conceitos de JavaScript na resolução de exercícios, desafios e criação de pequenos jogos.
